# English Quest — prototype minimal

Jeu d'apprentissage de l'anglais pour adultes et jeunes actifs tunisiens (niveau visé : A2 vers B1).

## Ce que contient ce prototype
- **Une quête** : « L'entretien d'embauche », avec les 4 compétences : écouter, lire, écrire, parler.
- **Série quotidienne** (jours consécutifs) et **points XP**, sauvegardés sur l'appareil du joueur.
- **Interface en arabe, français et anglais** (l'arabe s'affiche de droite à gauche).
- **Site web adapté au téléphone**, sans serveur : trois fichiers (`index.html`, `style.css`, `app.js`).

## Limites connues (volontaires pour ce prototype)
- L'écriture est vérifiée par des règles simples, pas encore par une IA.
- L'oral utilise la reconnaissance vocale du navigateur (Chrome conseillé). À tester avec des accents tunisiens réels.
- Pas de comptes joueurs, de ligues ni d'abonnement.
- Aucune donnée n'est envoyée sur Internet : rien n'est collecté.

## Publier le site
Dans GitHub : **Settings > Pages > Branch : main > Save**. L'adresse du jeu apparaît après une minute.

## Prochaines étapes proposées
1. Test avec 10 vrais utilisateurs.
2. Correction de l'écrit et de l'oral par IA (serveur sécurisé, coût par joueur à chiffrer).
3. Ligues hebdomadaires, plus de quêtes, test final noté (CECRL) avec attestation.
